# Task 5 — Security Incident Report

Written incident response report based on a given scenario — no scanning or lab work involved in this one, just working through how you'd actually respond to an incident.

## Scenario
An employee receives a phishing email pretending to be a Microsoft 365 password reset notice, clicks the link, and enters his real credentials on a fake login page.

## Objective
Prepare a professional incident response report covering what happened, what the risks are, what actions should be taken immediately, and how to prevent it from happening again.

## Report covers
- Incident Summary
- Initial Findings
- Possible Risks
- Immediate Actions Taken
- Containment
- Recovery Plan
- Future Prevention Recommendations

## Files in this folder
- `report.docx` / `report.pdf` — the full incident report (max 3 pages, as required)

## Note
This is a hypothetical scenario given as part of the internship task — no real company, employee, or incident is involved.
